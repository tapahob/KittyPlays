Enable Vulkan in Chrome

On Linux, enabling Vulkan can make hardware WebGPU available for AI, Hybrid, and AMD FidelityFX.

  1. Paste chrome://flags/#enable-vulkan into a new Chrome tab.
  2. Set Vulkan to Enabled, then click Relaunch.
  3. Return to this wizard and click Check again before continuing.

On systems with more than one GPU, Chrome may only report the adapter it is using.

Download the extension

Download and extract the Chrome extension ZIP into a folder named KittyPlays-Chrome. Keep that folder in place because Chrome loads the extension directly from it.

Download Chrome extension ZIP

If you already have the repository on this device, you can use its chrome-extension folder.

Load KittyPlays in Chrome

  1. Paste the address into a new Chrome tab. Turn on Developer mode.
  2. Click Load unpacked and select the extracted KittyPlays-Chrome folder. It contains manifest.json directly.
  3. If KittyPlays is already loaded from that folder, use Reload on its card.

Try it on YouTube

Open a video or reload an existing YouTube tab. The KittyPlays controls appear in the player next to the playback buttons. Choose a mode and a frame-rate target. Info shows the source and output FPS.

Open YouTube

Playback on macOS

KittyPlays starts in Optical Flow when Chrome identifies the base Apple M1 GPU. You can also choose AI or Hybrid if WebGPU is available. All three modes run directly in Chrome.

Select Max to follow the refresh rate Chrome can use on your current display.

AMD FidelityFX on Linux

KittyPlays selects FidelityFX by default when Chrome detects a Radeon adapter. FidelityFX uses hardware WebGPU inside Chrome and switches to Optical Flow when WebGPU is unavailable.

Legacy Vulkan helper for older builds

The current extension uses WebGPU. Use these downloads with an older extension build that supports the native helper.

  1. Download the Linux build script. Run it with Bash from the KittyPlays source folder.
  2. Download the registration script. Run it with Python 3 and supply the older extension ID and the path to the built helper.

Playback on Windows

AI, Hybrid, and Optical Flow process and display frames inside Chrome using graphics acceleration. No native helper is needed.
